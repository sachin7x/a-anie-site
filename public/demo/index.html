Wispr Webflow package · offline demo

Each link below loads one IIFE bundle from dist/ on this same server. The bundles' network calls are intercepted by the mock. No real Supabase or api.wisprflow.ai traffic.

Loading global.js…
Honest disclosure. The Wispr bundles were authored for Webflow-mounted pages with Webflow-generated DOM hooks (e.g. .w-tab-link.w--current, .wd_pill-wrap, id="contact-form"). On a standalone page those selectors don't exist, so most of the visible UI will not render. The demo proves the IIFEs execute, the Supabase client is constructed, and every fetch is intercepted — it does not reproduce the production Webflow look. For the full production look you'd need the original Webflow export, which Wispr keeps private (per REPORT.md §2).
