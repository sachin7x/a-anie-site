Changelog.

A weekly record of what changed, what broke, and what was added. New releases drop on Friday. The cadence is honest, not promised.

Last updated: 3 September 2026 · Tags: add feature, fix bug fix, docs documentation, site marketing site only

  • 0.4.23 September 2026site

    Added five new pages to mirror a credible information architecture without inventing content: Careers, Accessibility, Support, this Changelog, and a standalone Contact page. The wispr Flow demo mirror under /demo/ remains as a research artifact; it is not linked from the header.

  • 0.4.127 August 2026fixsite

    Replaced fabricated Subresource Integrity hashes on the Bootstrap CDN link with the real SHA-384 hashes. The fabricated hashes had silently blocked the stylesheet from loading, which made the navbar render as a vertical stacked list on every page. Computed the correct hashes with openssl dgst -sha384 -binary | openssl base64 -A and committed them to all seven HTML files in one pass.

  • 0.4.020 August 2026add

    Initial early-access release of the desktop dictation app. Supports English, Hindi, Marwari, and twelve other Indian languages; runs the speech-to-text model on-device via the bundled whisper.cpp binary; no audio is uploaded to any server. Tested on macOS 14 and macOS 15. Windows and Linux builds are not in this release.

  • 0.3.713 August 2026addfix

    Personalization: the app now learns the corrections a user accepts (e.g. “Rajesh” instead of “rajesh”) and biases the decoder toward them in future sessions. Personalization data is stored locally in ~/Library/Application Support/A-Anie/ on macOS and never leaves the device. Fixed a regression where the global hotkey conflicted with Spotlight on first install.

  • 0.3.56 August 2026adddocs

    Added the How it works docs page. The docs describe the on-device model, the supported languages, the keyboard shortcuts, the personalization model, and the limits of what the app does not do. Documentation lives at /how-it-works and is updated with each release.

  • 0.3.330 July 2026fix

    Memory leak in the audio capture thread after long sessions (90+ minutes of continuous dictation). Tracked to a retained reference in the VAD callback; the fix is to nil the reference on stop. Repro rate before the fix: ~1 in 8 long sessions. After: 0 in 200 test sessions.

  • 0.3.023 July 2026add

    Multi-language support: the app now accepts a per-session language selector, and the on-device model switches between language packs without restarting. The list of supported languages is in the index page's language section. The first launch still defaults to the system language.

  • 0.2.416 July 2026fix

    Corrected an attribution error on the marketing site. The previous version said the project was built by “Anjali from Kishangarh”; the developer is Sachin Dohdiya, also from Kishangarh. The two people are related but are not the same person, and the original copy was inaccurate. Replaced all references on the index, story, and contact sections.

  • 0.2.09 July 2026add

    Closed beta to a small list of users in Rajasthan, Delhi, and Bangalore. The list is currently full; new applicants are added when a slot opens. The Contact page is the way to ask for an invite; the reply rate is best-effort within a working week.

  • 0.1.02 July 2026add

    First public build. The app records from the system microphone, runs the audio through a whisper.cpp binary bundled with the .dmg, and pastes the resulting text at the cursor. That is the entire product. Everything else on the marketing site is forward-looking copy; the app does what is on this page, and no more.

What is next

Two things are queued for the next release, in this order: a Windows build, and a fix for the long-audio summary feature that has been broken since 0.3.5. Neither is promised for a specific date; they will land when they are ready, and they will show up here the day they ship.
